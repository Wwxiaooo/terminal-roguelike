# Terminal Roguelike · 终端风肉鸽

一个**单文件、零依赖**的浏览器 Roguelike 游戏。黑客 / 终端主题，绿色像素风 UI，打开 `index.html` 即玩，无需任何构建或服务器。

> 在线试玩（GitHub Pages）：https://wwxiaooo.github.io/terminal-roguelike/

---

## 玩法简介

你是一名潜入生产服务器的清理进程，目标是逐层清除「异常进程」、突破特权进程、最终干掉驻留 Boss，恢复被污染的日志文件系统。

- 关卡结构：**10 层「日志墓场」**，每 5 层出现特权进程，第 10 层为驻留 Boss。
- 战斗：走到异常进程旁边即可 `kill`；用魔法飞弹远程清理。
- 成长：击杀掉落装备 / 碎片 / 经验，回到主菜单用天赋点强化 build。

## 操作

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| `空格` | 等待一回合 |
| `F` | 释放魔法飞弹 |
| `ESC` | 返回主菜单 |
| `Ctrl` | 隐藏 / 显示操作提示 |

主菜单（初始页面）右上角提供**导出存档 / 导入存档**；主菜单内还有存档、天赋、成就、图鉴等入口。

---

## 主要特性

- **武器系统**：剑 / 匕首 / 战斧 / 战锤 / 法杖，各有主属性（力量 / 敏捷 / 智力）与基础攻击。
- **装备词缀**：装备随机生成主题词缀，影响攻击、防御、攻速、幸运等属性。
- **天赋树**：长线天赋（50 级，后期花费递增）与短线天赋并存，永久保留、可免费重置。
- **成就系统**：7 个跨局成就（首通、无伤、百杀、集齐神器等），达成有提示。
- **代码簿 / 图鉴**：跨局记录遇到的异常进程、装备构件、神器、特殊词条，未发现的显示 `???`。
- **地图分支**：每关前可选路线（中立 / 安全 / 宝藏 / 战斗 / 核心 / 精英），偏向不同；**Boss 房不可跳过**。
- **碎片经济**：装备可分解换碎片，碎片可重铸词缀或在商人处锻造稀有 / 史诗装备。
- **特殊房间**：普通层随机出现的哨兵 / 冲锋 / 克隆房，增加变数。
- **通关动画**：以 `rm -rf` 风格还原「清除污染日志、恢复文件系统」的黑客式结局。
- **存档导入 / 导出**：把全部进度（存档 + 天赋 + 成就 + 图鉴）打包成文本或文件，跨设备迁移。
- **绿色像素图标 UI**：统一风格的 SVG 像素图标，包括初始页面。

## 怎么玩

### 本地运行
直接用浏览器打开 `index.html` 即可，无需任何依赖或服务器。

### 在线运行
访问 GitHub Pages 网址（见顶部），任意有网络的浏览器直接开玩，公司 / 家里 / 手机都行。

---

## 数据存储与多设备同步

- 游戏进度（天赋、成就、图鉴、存档）保存在**浏览器的 `localStorage`**，按网站域名隔离——**是设备本地的，不随代码同步**。
- 因此「家里玩、公司接着玩」时，代码通过 GitHub 同步，但进度需要手动迁移：
  1. 家里：主菜单右上角「导出存档」→ 复制文本或下载 `.json` 备份。
  2. 公司：同一网址打开 → 「导入存档」→ 粘贴文本或选择文件 → 进度即恢复。

## 开发与贡献

本项目是**单文件**游戏，全部逻辑在 `index.html` 内。

```bash
# 克隆仓库
git clone https://github.com/Wwxiaooo/terminal-roguelike.git
cd terminal-roguelike

# 本地编辑 index.html 后，直接浏览器打开预览
# 提交并推送，GitHub Pages 通常 1 分钟内自动更新
git add index.html
git commit -m "your change"
git push
```

> 注意：本仓库的所有游戏进度数据不进入版本控制（仅代码）。`.gitignore` 已排除本地项目数据目录。
